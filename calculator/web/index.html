How to read this

  • Execution is the infrastructure and vendor bill. Operations, cognitive load and exit are shown in hours, because turning every hour into dollars can imply more precision than the estimate deserves. Add an hourly rate only if you want a dollar figure.
  • The complexity budget compares those hours with the share of team capacity you are willing to spend keeping the platform running. The default (10%) is an assumption.
  • Use it to compare options and start a conversation, then check the result against real measures such as deployment frequency, MTTR and pages per platform.
  • Formulas: docs/tco-formula.md. Data: calculator/tco-model.csv.
