# ADR 0101: Adopt a service mesh because everyone does

- **Status:** Accepted
- **Date:** 2025-03-01
- **Owner:** Platform lead

## Context

Large companies run a service mesh, so we should too.

## Alternatives considered

We looked at the leading mesh and it is the standard choice.

## Decision

Roll the mesh out to every service as our strategic traffic layer.

## Evidence

The vendor demo ran smoothly on a laptop.

## Exit criteria

None. It is strategic.
