# ADR 0102: Move order events to Kafka

- **Status:** Accepted
- **Date:** 2025-03-01
- **Review date:** 2025-09-01
- **Owner:** Platform lead

## Context

We want to be event-driven. Kafka is what modern teams use for this.

## Decision

Move all order events to Kafka for every service in one release.

## Evidence

Everyone is excited.

## Exit criteria

Revisit if it fails.
